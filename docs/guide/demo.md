# Online Demo

This page embeds the same Vue 2 demo app used in local development. That keeps the online documentation and the standalone demo in sync without duplicating tracking scenarios.

## Included cases

| Route | What it validates |
| --- | --- |
| `basic` | Directive value payloads for click and browse tracking |
| `compatibility` | Legacy `track-params` string and object compatibility |
| `exposure` | `threshold`, `duration`, `once`, and queue-related exposure behavior |
| `manual` | `clickEvent`, `browseEvent`, and `exposureEvent` manual APIs |
